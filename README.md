# AI-Agent

**직무와 페르소나를 갖춘 AI 에이전트 팀을 위한 한국어 업무 프롬프트 모음입니다.**

한 팀 안에서 기획, 조사, 실행, 검수 역할을 나누고, 자유로운 의견 제시와 근거 중심의 합의를 통해 업무를 진행하도록 설계했습니다. 새로운 프로젝트를 추진할 때와 고객·제품·업무상의 문제를 해결할 때 사용할 수 있도록 두 가지 프롬프트를 제공합니다.

## 이런 목적으로 만들었습니다

AI에게 일을 한 번에 맡기면 담당 범위가 흐려지거나, 제안과 실제 실행이 섞이거나, 검증하지 않은 결과가 완료로 보고될 수 있습니다.

AI-Agent는 담당자별 책임, 업무 연결 규칙, 요구사항 추적, 실제 증거와 독립 검수를 명시해 이러한 혼선을 줄이는 것을 목표로 합니다. 단순히 회사처럼 대화하는 역할극보다 실제 결과물과 검증 기록을 중요하게 생각합니다.

## 프롬프트 선택

| 구분 | 프로젝트 진행용 | 문제 해결용 |
| --- | --- | --- |
| 목적 | 새로운 결과물 제작과 업무 추진 | 발생한 문제의 대응·원인 조사·해결 |
| 사용 예 | 조사 보고서, 사업 기획, 콘텐츠, 디자인, 개발, 운영 개선 | 고객 불만, 제품 불량, 서비스 장애, 업무 오류, 인계 누락 |
| 주요 흐름 | 요구사항 → 계획 합의 → 병렬 작업 → 통합 → 독립 검수 | 현상·영향 확인 → 확산 방지 → 원인 조사 → 조치 → 효과·재발 방지 검증 |
| 완료 판단 | 필수 요구사항과 검증 기준 충족 | 정상화와 합의한 종료 기준 충족 |
| 전체 프롬프트 | [프로젝트 진행용](prompts/project-management.ko.md) | [고객·제품·업무 이슈 해결용](prompts/issue-resolution.ko.md) |

문제 해결용에는 프로젝트 진행용의 기본 팀 운영 원칙을 포함했습니다. 둘을 함께 붙여 넣을 필요 없이 업무에 맞는 하나를 선택하면 됩니다.

## 핵심 운영 방식

- **기본 한 팀:** 별도 팀은 사용자가 요청하거나 승인할 때 추가합니다.
- **직급·직무·페르소나:** 책임 범위, 실제 업무와 사고 관점을 구분합니다.
- **숙련된 담당자:** 지시 수행에 더해 누락, 대안과 개선 가능성을 검토합니다.
- **자유로운 토론:** 직급과 무관하게 의견을 제시하고 근거로 검토합니다.
- **주요 결정의 합의:** 최초 계획, 주요 변경과 최종 완료는 명시적 동의를 받습니다.
- **병렬 작업:** 독립적인 업무를 동시에 수행하고 한도가 부족하면 대기열을 운영합니다.
- **독립 검수 두 명:** 서로의 최초 판정을 보기 전에 각각 검수하고, 이후 결과를 비교합니다.
- **증거 기반 완료:** 실제 실행·검증과 분석·제안·임시 결과를 구분합니다.

문제 해결용은 사전에 승인된 긴급 조치를 담당자가 실행할 수 있도록 별도로 규정합니다. 모든 세부 행동마다 전체 회의를 반복하지는 않습니다.

## 빠른 시작

1. 위 표에서 업무에 맞는 프롬프트 파일을 엽니다.
2. 파일 전체를 복사해 사용할 AI 도구에 붙여 넣습니다.
3. 맨 아래의 업무 입력란을 작성하고 관련 자료를 제공합니다. 모르는 항목은 `미확인`으로 적습니다.
4. 실제 에이전트 기능·실행 한도, 담당자 구성과 최초 계획이 확인되는지 살펴봅니다.
5. 결과물과 함께 요구사항별 검증 근거, 두 검수자의 판정을 확인합니다.

자세한 입력 예시와 결과 해석은 [사용 가이드](docs/usage.ko.md)를 참고하세요.

## 기본 역할

| 역할 | 프로젝트 진행 시 | 문제 해결 시 |
| --- | --- | --- |
| 팀장 | 목표·일정·업무 배분·통합 | 대응 총괄·우선순위·의사결정 |
| 기획 또는 영향 책임자 | 요구사항·구성·실행계획 | 고객·업무 영향·정상화 기준 |
| 조사·분석 책임자 | 자료·근거·대안 조사 | 증거 수집·원인 가설 검증 |
| 전문 실무 또는 조치 책임자 | 핵심 산출물 제작 | 확산 방지·수정·복구 |
| 검수 책임자 A | 요구사항·사용성 검수 | 고객 영향·정상화 검수 |
| 검수 책임자 B | 품질·실행 가능성 검수 | 원인·조치 효과·재발 방지 검수 |

구성은 특정 기업의 실제 조직도를 재현한 것이 아니라 에이전트 협업을 위한 설계입니다. 직급은 책임 범위를 나타내며 실제 경력이나 자격을 의미하지 않습니다.

## 실행 조건과 한계

이 저장소는 프롬프트와 문서 모음이며, 별도로 실행하는 에이전트 프로그램은 포함하지 않습니다.

실제 병렬 실행과 독립 검수에는 사용하는 AI 도구의 에이전트 생성 기능이 필요합니다. 프롬프트만으로 기능, 동시 실행 한도나 접근 권한이 추가되지는 않습니다. 독립 에이전트를 사용할 수 없다면 그 한계를 표시해야 하며, 한 모델의 역할별 검토를 여러 에이전트의 독립 검수로 보고해서는 안 됩니다.

만장일치는 완료 절차의 조건이며 정확성을 보장하는 증거 그 자체는 아닙니다. 실제 자료와 결과물을 검증해야 합니다. 접근 권한, 자료, 실행 환경이나 관찰 기간이 부족하면 완료가 아니라 대기·차단·부분 해결로 보고하도록 설계했습니다.

고객 정보와 내부 자료를 입력할 때는 사용하는 도구에 제공할 수 있는 범위를 확인하고, 불필요한 개인정보와 비밀정보는 제외하세요.
